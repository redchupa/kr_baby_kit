# Korean Baby Kit (한국 영유아 키트)

Home Assistant integration for child growth percentiles, immunization schedules, and checkup milestones.

- **Growth charts (LMS)**: Supports both South Korea (KDCA 2017) and International (WHO Child Growth Standards 2006 / 2007 Reference).
- **Immunizations & checkups**: Automatic calendars, open-window deadlines, next-window start sensors, and optional completion tracking.
- **Dashboard entry & Assist**: Number entities for quick daily measurements and per-child LLM API for Home Assistant Assist.
- **Childcare tuition (KR profile)**: Standard tuition, government subsidy, and parent share based on birth-year age class.
- **Offline & localized**: Bundled public reference tables, no API keys required, English and Korean UI/entity translations.

> For reference only. Does not replace professional pediatric care.
